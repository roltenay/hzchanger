# HzChanger ⚡

A lightweight, minimalist C# Windows Forms application designed to quickly switch your monitor's display refresh rate between **60 Hz** and your monitor's **Maximum supported Hz** (e.g., 120 Hz, 144 Hz, 165 Hz, 240 Hz) with a single click.

---

## ✨ Features

- **One-Click Refresh Rate Switch:** Instantly toggle between 60 Hz and your monitor's highest refresh rate.
- **Dynamic Hz Detection:** Automatically detects your display's current refresh rate and maximum supported rate using Windows User32 API (`EnumDisplaySettings`).
- **Minimalist & Clean UI:** Designed with a compact footprint, modern `Segoe UI` typography, and standard screen placement.
- **Always-on-Top Support:** Stays accessible when needed during gaming or productivity workflows.

---

## 🛠️ Built With

- **C#** (.NET Windows Forms)
- **Windows API** (`user32.dll` - `EnumDisplaySettings`, `ChangeDisplaySettings`)
